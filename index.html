まるっと教養 管理ツール

YouTubeチャンネル「まるっと教養」の運営者が、自分のチャンネルを管理するためだけに使う個人用ツールです。一般の方が利用することはありません。

A personal tool used only by the owner of the YouTube channel "Marutto Kyoyo" to manage their own channel. It is not offered to the public.

プライバシーポリシー / Privacy Policy

最終更新日：2026年9月30日

利用するデータ

YouTube Data API と YouTube Analytics API を通じて、運営者自身のチャンネルについて次の情報を利用します。

  • チャンネル情報、動画のタイトル・説明文・タグ・サムネイル
  • 視聴回数、視聴時間、高評価数などの分析データ

利用目的

運営者自身の動画の情報を更新すること、および動画の成績を分析することにのみ使います。

保存と共有

  • 認証情報と取得したデータは、運営者のパソコンの中にだけ保存します。
  • データを第三者に販売・提供・共有することはありません。
  • 広告や、上記以外の目的には使いません。

アクセスの取り消し

Googleアカウントの「サードパーティ製のアプリとサービス」から、いつでもこのツールのアクセスを取り消せます。

Google API サービスのユーザーデータに関するポリシー

このツールによる Google API から取得した情報の利用は、Google API Services User Data Policy（Limited Use の要件を含む）に従います。

English summary: This tool accesses only the owner's own YouTube channel data (channel info, video metadata, thumbnails, and analytics) via the YouTube Data API and YouTube Analytics API, solely to update the owner's videos and analyze their performance. Credentials and data are stored only on the owner's computer and are never sold, shared, or transferred to third parties. Access can be revoked at any time at https://myaccount.google.com/permissions. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
